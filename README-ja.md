# CASEC Sprint - スマホで使う方法

このアプリは、ホーム画面に追加して使えるPWA（Webアプリ）です。スコア・解答履歴は、各端末のブラウザ内だけに保存されます。スマホとPCで記録は共有されません。

リスニング画面では、再生ボタンの下にある「声」と「速度」を変更できます。最初は「おすすめの英語音声（自動）」と「聞きやすい」を試してください。聞こえにくい場合は、声を切り替えたうえで「ゆっくり」にしてください。

## 一番簡単: GitHub Pagesで公開する

1. GitHubにログインし、`casec-sprint` という新しいリポジトリを作ります。
2. このフォルダ内のファイルをすべてアップロードします。
3. リポジトリの **Settings** → **Pages** を開き、**Build and deployment** の **Source** で **Deploy from a branch** を選びます。
4. Branchは `main`、フォルダは `/(root)` を選び、保存します。
5. 表示された `https://ユーザー名.github.io/casec-sprint/` をスマホのSafariまたはChromeで開きます。
6. iPhoneでは共有ボタン → **ホーム画面に追加**、Androidではメニュー → **アプリをインストール** を選びます。

公開後、反映に数分かかることがあります。個人の氏名や成績表PDFはリポジトリにアップロードしないでください。

## 補足

- GitHub Pagesの無料プランでは、通常リポジトリを公開設定にする必要があります。アプリ内には個人データを入れていません。
- 自宅のWi-Fiだけで一時利用する方法もありますが、PCの電源を入れ続ける必要があるため、この使い方には公開型の方法をおすすめします。
